## 1. Txの確認 [#sec-1]

<Callout type="error" title="重要な確認事項">

ブロック生成を行うには、リレー/BPで「Total Tx」が増加していることを確認してください。  
プール登録から約12〜24時間後に、Incoming接続と「Total Tx」の増加を確認します。  
増加していない場合は、ファイアウォール設定やトポロジーファイルの内容を再確認してください。

</Callout>

<Callout type="warning" title="確認事項">

プール登録から約12〜24時間後に「Total Tx」が増加しているか確認してください。

</Callout>


<Tabs items={["リレー/BP"]}>
<Tab value="リレー/BP">

```bash
cd $NODE_HOME/scripts
./gLiveView.sh
```

</Tab>
</Tabs>

## 2. TraceMempoolの無効化 [#sec-2]

<Callout type="error" title="重要な最終調整">

ノード稼働時のCPU/メモリ消費を抑えるため、`TraceMempool` を無効化します。  
この設定はプール運営時のパフォーマンス改善に有効な推奨設定です。

- トランザクション流入ログの記録により、CPU/メモリ消費が増加する場合があります。
- 無効化後は「Total Tx」「Pending Tx」は増加しなくなりますが、事前に増加を確認できていれば問題ありません。

</Callout>


<Tabs items={["リレー/BP"]}>
<Tab value="リレー/BP">

```bash
sed -i $NODE_HOME/${NODE_CONFIG}-config.json \
  -e "s/TraceMempool\": true/TraceMempool\": false/g"
```

</Tab>
</Tabs>

**ノードを再起動してください。**
```bash
sudo systemctl reload-or-restart cardano-node
```

ノードログにエラーが出ていないか確認してください。
```bash
journalctl --unit=cardano-node --follow
```


## 3. ブロック生成可能状態チェック [#sec-3]

**SJGツールを導入してください。**

導入手順は、[SJGツール導入設定](/cardano/operation/sjg-tool-setup)を参照してください。

**SJGツールを実行してください。**

```bash
gtool
```

`[2] ブロック生成状態チェック` を選択してください。


<Callout type="warning" title="重要な確認事項">

[プール運用マニュアル](/cardano/operation)を必ず確認し、プール運営について学習してください。

</Callout>
