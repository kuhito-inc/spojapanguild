cabal build all cardano-cli

## 4. cardano-tracerの設定 [#sec-8]

Cardano Nodeから転送されるtrace（ログ）およびmetricsを受信するため、各Cardano Node稼働サーバーで`cardano-tracer`を設定します。

<Tabs items={["全ノード"]}>

<Tab value="全ノード">

### cardano-tracerの確認 [#sec-9]

`cardano-tracer`がインストールされていることを確認します。

```bash
cardano-tracer --version
```

### Tracer用ディレクトリの作成 [#sec-10]

Tracer用のディレクトリとログ保存用のディレクトリを作成します。

```bash
mkdir -p ${NODE_HOME}/tracer
mkdir -p ${NODE_HOME}/logs
```

### tracer-config.jsonの取得 [#sec-11]

Tracer用の設定ファイルを取得します。

```bash
cd ${NODE_HOME}/tracer
```

```bash
wget --no-use-server-timestamps https://spojapanguild.net/node_config/11.1.2/${NODE_CONFIG}-tracer-config.json -O ${NODE_CONFIG}-tracer-config.json
```

### tracer-config.jsonの設定 [#sec-12]

`tracer-config.json`のログ保存先、Unix SocketのPATH、Network Magicを環境に合わせて変更します。

```bash
sed -i \
  -e "s|\"logRoot\": \"\"|\"logRoot\": \"${NODE_HOME}/logs\"|" \
  -e "s|\"contents\": \"\"|\"contents\": \"${NODE_HOME}/tracer/socket\"|" \
  -e "s|\"networkMagic\": 0|\"networkMagic\": ${CARDANO_NODE_NETWORK_ID}|" \
  ${NODE_CONFIG}-tracer-config.json
```


### cardano-tracerのsystemd service作成 [#sec-13]

`cardano-tracer`のsystemd serviceファイルを作成します。

```bash
cat > ${NODE_HOME}/tracer/cardano-tracer.service << EOF
[Unit]
Description=Cardano Tracer Service
Wants=network-online.target
After=network-online.target
Before=cardano-node.service
StartLimitIntervalSec=0

[Service]
User=${USER}
Type=simple
WorkingDirectory=${NODE_HOME}
ExecStart=/usr/local/bin/cardano-tracer --config ${NODE_HOME}/tracer/${NODE_CONFIG}-tracer-config.json
Restart=always
RestartSec=5
LimitNOFILE=32768

[Install]
WantedBy=multi-user.target
EOF
```

systemdへ配置します。

```bash
sudo cp ${NODE_HOME}/tracer/cardano-tracer.service /etc/systemd/system/cardano-tracer.service
```

権限を設定します。

```bash
sudo chmod 644 /etc/systemd/system/cardano-tracer.service
```

systemdへ設定を反映します。

```bash
sudo systemctl daemon-reload
```

Tracerをサーバー起動時に自動起動し、起動します。

```bash
sudo systemctl enable --now cardano-tracer.service
```

## 5. ノード起動スクリプトの作成 [#sec-15]

起動スクリプトには、ディレクトリ、ポート番号、DBパス、構成ファイルパス、トポロジーファイルパスなど、Cardanoノードを実行するために必要な変数が含まれています。

<Tabs items={["リレー", "BP"]}>
<Tab value="リレー">

リレーで使用するポート番号を指定してターミナルで実行します。
```bash
PORT=6000
```

起動スクリプトファイルを作成する
```bash
cat > $NODE_HOME/startRelayNode1.sh << EOF 
#!/bin/bash
DIRECTORY=$NODE_HOME
PORT=${PORT}
HOSTADDR=0.0.0.0
TOPOLOGY=\${DIRECTORY}/${NODE_CONFIG}-topology.json
DB_PATH=\${DIRECTORY}/db
SOCKET_PATH=\${DIRECTORY}/db/socket
CONFIG=\${DIRECTORY}/${NODE_CONFIG}-config.json
TRACER_SOCKET_PATH=\${DIRECTORY}/tracer/socket
/usr/local/bin/cardano-node run +RTS -N --disable-delayed-os-memory-return -I0.1 -Iw300 -A16m -F1.5 -H2500M -RTS --topology \${TOPOLOGY} --database-path \${DB_PATH} --socket-path \${SOCKET_PATH} --host-addr \${HOSTADDR} --port \${PORT} --config \${CONFIG} --tracer-socket-path-connect \${TRACER_SOCKET_PATH}
EOF
```

</Tab>
<Tab value="BP">


<Callout type="error" title="注意">

* BPノードポートはセキュリティを高めるために、`49513`～`65535`までの任意番号を設定してください。  
ここで設定する番号は、`SSH`ポート番号とは別の番号を設定してください。

</Callout>

## 7. 自動起動の設定(systemd) [#sec-17]

先程のスクリプトだけでは、ターミナル画面を閉じるとノードが終了してしまうので、スクリプトをサービスとして登録し、自動起動するように設定します。

<Callout type="info" title="ノード起動にsystemdを使う理由">

- サーバー再起動後もノードが自動起動  
- プロセスが異常終了したときに自動で再起動（ユニットの `Restart` 設定に従う）

</Callout>


ユニットファイルを作成します。

<Tabs items={["リレー", "BP"]}>
<Tab value="リレー">


```bash
cat > $NODE_HOME/cardano-node.service << EOF 
# The Cardano Node Service (part of systemd)
# file: /etc/systemd/system/cardano-node.service 

[Unit]
Description     = Cardano Node Service
Wants           = network-online.target
After           = network-online.target 

[Service]
User            = ${USER}
Type            = simple
WorkingDirectory= ${NODE_HOME}
ExecStart       = /bin/bash -c '${NODE_HOME}/startRelayNode1.sh'
KillSignal=SIGINT
RestartKillSignal=SIGINT
TimeoutStopSec=300
LimitNOFILE=32768
Restart=always
RestartSec=5

[Install]
WantedBy	= multi-user.target
EOF
```

</Tab>
<Tab value="BP">


```bash
cat > $NODE_HOME/cardano-node.service << EOF 
# The Cardano Node Service (part of systemd)
# file: /etc/systemd/system/cardano-node.service 

[Unit]

[Service]

RestartKillSignal=SIGINT
TimeoutStopSec=300
LimitNOFILE=32768
Restart=always
RestartSec=5

[Install]
WantedBy    = multi-user.target

```

</Tab>
</Tabs>

`/etc/systemd/system`にユニットファイルをコピーし、権限を付与します。
```bash
sudo cp $NODE_HOME/cardano-node.service /etc/systemd/system/cardano-node.service
```
```bash
sudo chmod 644 /etc/systemd/system/cardano-node.service
```

OS起動時にサービスの自動起動を有効にします。
```bash
sudo systemctl daemon-reload
```
```bash

```

システム起動後にログモニターを表示します。
```bash

```
> コマンド入力に戻る場合は「`Ctrl+C`」（この場合ノードは終了しません）

### 便利なエイリアス設定 [#sec-18]

<Callout type="info" title="エイリアス設定">

スクリプトへのパスを通し、任意の単語で起動出来るようにします。
```bash
echo alias cnode='"journalctl -u cardano-node -f"' >> $HOME/.bashrc
echo alias cnstart='"sudo systemctl start cardano-node"' >> $HOME/.bashrc
echo alias cnrestart='"sudo systemctl reload-or-restart cardano-node"' >> $HOME/.bashrc
echo alias cnstop='"sudo systemctl stop cardano-node"' >> $HOME/.bashrc
echo alias cnreload='"pkill -HUP cardano-node"' >> $HOME/.bashrc
source $HOME/.bashrc
```

単語を入力するだけで、ノードの起動状態(ログ)を確認できます。  
```yaml title="期待される表示例：" noCopy
cnode ・・・ログ表示
cnstart ・・・ノード起動
cnrestart ・・・ノード再起動
cnreload ・・・設定再読み込み
cnstop ・・・ノード停止
```

</Callout>



## 8. gLiveViewのインストール [#sec-19]

`cardano-node`はログが流れる画面だけでは何が表示されているのかよくわかりません。  
それを視覚的に確認できるツールが`gLiveView`です。

> `gLiveView`は重要なノードステータス情報を表示し、systemdサービスとうまく連携します。  
> このツールを作成した [Guild Operators](https://cardano-community.github.io/guild-operators/#/Scripts/gliveview)の功績によるものです。


`gLiveView`をインストールします。
```bash
mkdir -p $NODE_HOME/scripts
cd $NODE_HOME/scripts
sudo apt install bc tcptraceroute -y
```

`gLiveView`のバイナリファイルをダウンロードします。
```bash
curl -o gLiveView.sh https://raw.githubusercontent.com/cardano-community/guild-operators/master/scripts/cnode-helper-scripts/gLiveView.sh
curl -o env https://raw.githubusercontent.com/cardano-community/guild-operators/master/scripts/cnode-helper-scripts/env
chmod 755 gLiveView.sh
```

**短縮する場合：** [Mithril による DB 同期](/cardano/operation/mithril-client) で、初回を **目安30分以内** にできます。
