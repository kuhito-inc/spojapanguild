---
title: "BP用キーの生成"
---

ステークプールの運用に必要な各種キーを **BP** 上で生成します。

<Callout type="error" title="鍵ファイルの取り扱いについて">

各キーファイル は **プール運営の根幹となる鍵** です。<mark>流出するとプールの乗っ取りにつながる可能性があります。</mark>  
本マニュアルはテストネットのため BP 上で生成しますが、本番運用ではエアギャップ（オフライン）環境での生成・保管を推奨します。 

</Callout>

<Callout type="warn" title="事前確認">

[ノード構築](/cardano/leios-testnet/node-setup) が完了し、同期が `100.00` になってから以降の手順を実施してください。

```bash
cardano-cli query tip | jq -r '.syncProgress'
```
```yaml title="期待される表示例：" noCopy
"100.00"
```

</Callout>


<Callout type="info" title="生成するキー一覧">

| ファイル | 用途 |
| :---- | :---- |
| `payment.vkey` / `payment.skey` | 支払いアドレス用キー |
| `stake.vkey` / `stake.skey` | ステークアドレス用キー |
| `node.vkey` / `node.skey` / `node.counter` | コールドキー（プールの根幹） |
| `kes.vkey` / `kes.skey` | KESキー |
| `vrf.vkey` / `vrf.skey` | VRFキー |
| `node.cert` | 運用証明書 |

</Callout>


## 1. 支払い・ステークキーの作成 [#sec-2]

```bash
cd $NODE_HOME
cardano-cli dijkstra address key-gen \
  --verification-key-file payment.vkey \
  --signing-key-file payment.skey
cardano-cli dijkstra stake-address key-gen \
  --verification-key-file stake.vkey \
  --signing-key-file stake.skey
```

## 2. コールドキーの作成 [#sec-3]

```bash
mkdir -p "$HOME/cold-keys"
cd "$HOME/cold-keys"
```

```bash
cardano-cli dijkstra node key-gen \
  --cold-verification-key-file $HOME/cold-keys/node.vkey \
  --cold-signing-key-file  $HOME/cold-keys/node.skey \
  --operational-certificate-issue-counter-file $HOME/cold-keys/node.counter
```


## 4. KES・VRFキーの作成 [#sec-4]

```bash
cd $NODE_HOME
cardano-cli dijkstra node key-gen-KES \
  --verification-key-file kes.vkey \
  --signing-key-file kes.skey
cardano-cli dijkstra node key-gen-VRF \
  --verification-key-file vrf.vkey \
  --signing-key-file vrf.skey
```


## 5. 支払いアドレスの作成 [#sec-5]

```bash
cardano-cli dijkstra address build \
  --payment-verification-key-file payment.vkey \
  --stake-verification-key-file stake.vkey \
  --out-file payment.addr
echo $(cat payment.addr)
```


## 6. Faucetからの入金 [#sec-6]

<Callout type="info" title="tADAの請求">

```
echo $(cat $NODE_HOME/payment.addr)
```

表示された支払いアドレスを `address(required):` に貼り付け、テスト用 tADA を請求します。

[faucet.leios.play.dev.cardano.org/basic-faucet](https://faucet.leios.play.dev.cardano.org/basic-faucet)

</Callout>


入金後、残高を確認します。

```bash
cd $NODE_HOME
cardano-cli dijkstra query utxo --address "$(cat payment.addr)" --output-text
```
```yaml title="期待される表示例：" noCopy
                           TxHash                                 TxIx        Amount
--------------------------------------------------------------------------------------
9e0c10b599606a5**********************************************     0    10000000000 lovelace + TxOutDatumNone
```
> UTxO が表示されれば入金完了です。


## 7. 運用証明書の作成 [#sec-7]

ジェネシスから `slotsPerKESPeriod` を取得し、現在のスロットから KES Period を算出します。

```bash
cd $NODE_HOME
slotsPerKESPeriod=$(jq -r '.slotsPerKESPeriod' "$NODE_HOME/shelley-genesis.json")
echo slotsPerKESPeriod: ${slotsPerKESPeriod}
slotNo=$(cardano-cli query tip | jq -r '.slot')
echo slotNo: ${slotNo}
kesPeriod=$(( slotNo / slotsPerKESPeriod ))
echo kesPeriod: ${kesPeriod}
```

運用証明書（`node.cert`）を作成します。

```bash
cd $NODE_HOME
cardano-cli dijkstra node issue-op-cert \
  --kes-verification-key-file kes.vkey \
  --cold-signing-key-file $HOME/cold-keys/node.skey \
  --operational-certificate-issue-counter-file $HOME/cold-keys/node.counter \
  --kes-period "$kesPeriod" \
  --out-file node.cert
```

キーの生成と入金が完了したら、[ステークプール登録](/cardano/leios-testnet/stake-pool-register) に進んでください。

</Callout>
