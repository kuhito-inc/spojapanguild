<Callout type="warn" title="Musashi-Testnetについて">

`Musashi-Testnet` は仕様・バージョンが更新されることがあります。  
新しいリリースが公開されたら、以下の手順で `/usr/local/bin` の `cardano-node` / `cardano-cli` を差し替えます。  
またチェーンがリスピン(リセット)した場合はプールを再登録する必要があります。

</Callout>


## 1. cardano-node / cardano-cliのアップデート [#sec-1]

ノードを停止します。
```bash
sudo systemctl stop cardano-node
```

最新のリリースタグを GitHub API から取得します。
```bash
RELEASE=$(curl -s "https://api.github.com/repos/input-output-hk/ouroboros-leios/releases?per_page=20" \
  | jq -r '[.[] | select(.draft == false)
            | select([.assets[].name] | index("cardano-node-leios-x86_64-linux.tar.gz"))]
           | sort_by(.published_at) | last | .tag_name')
echo "RELEASE=${RELEASE}"
```

<Callout type="warn" title="リリースタグについて">

Leios のリリースはすべて **Pre-release** として公開されているため、`releases/latest` API では取得できません。  
`RELEASE=` が空で表示された場合や、特定のバージョンを指定したい場合は、[Releases](https://github.com/input-output-hk/ouroboros-leios/releases) ページで確認のうえ `RELEASE=prototype-2026wXX` の形式で直接指定してください。

</Callout>


バイナリとチェックサムをダウンロードします。
```bash
mkdir -p $HOME/git
cd $HOME/git
wget -O cardano-node-leios-x86_64-linux.tar.gz https://github.com/input-output-hk/ouroboros-leios/releases/download/${RELEASE}/cardano-node-leios-x86_64-linux.tar.gz
wget -O cardano-node-leios-x86_64-linux.sha256 https://github.com/input-output-hk/ouroboros-leios/releases/download/${RELEASE}/cardano-node-leios-x86_64-linux.sha256
```

チェックサムを検証します。
```bash
sha256sum -c cardano-node-leios-x86_64-linux.sha256
```
```yaml title="期待される表示例：" noCopy
cardano-node-leios-x86_64-linux.tar.gz: OK
```

アーカイブを展開し、`/usr/local/bin` のバイナリを差し替えます。
```bash
tar -xzf cardano-node-leios-x86_64-linux.tar.gz
```
```bash
sudo cp bin/cardano-node /usr/local/bin/cardano-node
sudo cp bin/cardano-cli /usr/local/bin/cardano-cli
sudo chmod +x /usr/local/bin/cardano-node /usr/local/bin/cardano-cli
```

バージョンが更新されたことを確認します。
```bash
cardano-node --version
cardano-cli --version
```
> cardano-node 11.1.0.164 - linux-x86_64 - ghc-9.6  
> git rev 6971bb527288d0f362147fbe318c0e9c84312ab3  

> cardano-cli 11.1.0.0 - linux-x86_64 - ghc-9.6  
> git rev 6971bb527288d0f362147fbe318c0e9c84312ab3  


ノードを起動し、同期状況を確認します。
```bash
sudo systemctl start cardano-node
```

チェーン同期状況を確認する
```bash
glive
```

2. チェーンがリスピン(リセット)した場合

既存の鍵ファイルを使用してプールを再登録できます。

<Callout type="warn" title="Musashi-Testnetについて">

リスピン前に作成した鍵ファイル類が`$NODE_HOME`に揃っていることを前提とします
- `kes.skey` / `kes.vkey`
- `vrf.skey` / `vrf.vkey`
- `bls.skey` / `bls.vkey`
- `payment.skey` / `payment.vkey`
- `stake.skey` / `stake.vkey`
- `node.vkey` / `node.skey` / `node.counter`
- `stake.cert`
- `musashiMetaData.json` / `musashiMetaDataHash.txt` (メタデータの値を変更する場合は再作成が必要です)


</Callout>
