---
title: "ノード構築"
---

リレー・BP とも、ノードの基本構築手順は共通です。  
**リレーサーバー・BPサーバーの両方**で本ページの手順を実施してください。  
まずは両ノードともリレーとして起動してチェーンを同期させ、BP は後の手順（[BP用キーの生成](/cardano/leios-testnet/bp-key-setup)）でブロック生成モードへ切り替えます。

<Callout type="warn" title="事前準備">

ノード構築の前に、**リレーサーバー・BPサーバーの両方**で [Ubuntu初期設定](/cardano/setup/ubuntu-setup) を実施してください。  
作業用ユーザーの作成、SSHの鍵認証、ファイアウォール（UFW）、時刻同期などを設定します。  
UFW を有効化した場合は、SSHポートに加えてノード待受ポート `3010` の許可が必要です（リレーは外部から、BP はリレーのIPからのみ許可してください）。

</Callout>

<Callout type="info" title="本ページの構成">

- 公式が配布する**リリースバイナリ**を `/usr/local/bin` に配置し、**systemd** で常駐させる、SJG従来と同じ構成です。
- Leios プロトタイプのバイナリは**静的リンク**されているため、`libsodium` / `secp256k1` / `blst` の導入やソースからのビルドは不要です。
- Musashi-Testnet は仕様やバージョンが都度変更される可能性があります。新しいリリースが公開された場合は [ノードアップデート](/cardano/leios-testnet/node-update) の手順で差し替えてください。

</Callout>


## 1. 依存パッケージのインストール [#sec-1]

パッケージを更新し、`Ubuntu` を最新の状態に保ちます。

```bash
sudo apt update && sudo apt upgrade -y
```

必要なパッケージをインストールします。
```bash
sudo apt install curl jq git wget -y
```


## 2. cardano-node / cardano-cliのインストール [#sec-2]

公式リポジトリの [Releases](https://github.com/input-output-hk/ouroboros-leios/releases) で配布されているバイナリを導入します。

最新のリリースタグを GitHub API から取得します。

```bash
RELEASE=$(curl -s "https://api.github.com/repos/input-output-hk/ouroboros-leios/releases?per_page=20" \
  | jq -r '[.[] | select(.draft == false)
            | select([.assets[].name] | index("cardano-node-leios-x86_64-linux.tar.gz"))]
           | sort_by(.published_at) | last | .tag_name')
echo "RELEASE=${RELEASE}"
```
```yaml title="期待される表示例：" noCopy
RELEASE=prototype-2026w31a
```

<Callout type="warn" title="リリースタグについて">

Leios のリリースはすべて **Pre-release** として公開されているため、`releases/latest` API では取得できません。  
上記コマンドは、リリース一覧から `cardano-node-leios-x86_64-linux.tar.gz` を持つ最も新しいものを選択します。  
`RELEASE=` が空で表示された場合は、[Releases](https://github.com/input-output-hk/ouroboros-leios/releases) ページで最新のタグを確認し、`RELEASE=prototype-2026wXX` の形式で直接指定してください。  
`aarch64` 環境の場合は、上記コマンドと以降のファイル名を `cardano-node-leios-aarch64-linux` / `cardano-node-leios-aarch64-darwin` に読み替えてください。

</Callout>


作業用ディレクトリを作成し、バイナリとチェックサムをダウンロードします。

```bash
mkdir -p $HOME/leios-bin
cd $HOME/leios-bin
wget https://github.com/input-output-hk/ouroboros-leios/releases/download/${RELEASE}/cardano-node-leios-x86_64-linux.tar.gz
wget https://github.com/input-output-hk/ouroboros-leios/releases/download/${RELEASE}/cardano-node-leios-x86_64-linux.sha256
```

チェックサムを検証します。
```bash
sha256sum -c cardano-node-leios-x86_64-linux.sha256
```
```yaml title="期待される表示例：" noCopy
cardano-node-leios-x86_64-linux.tar.gz: OK
```
> `OK` 以外が表示された場合はダウンロードをやり直してください。

アーカイブを展開します。
```bash
tar -xzf cardano-node-leios-x86_64-linux.tar.gz
```
> `bin/cardano-node` と `bin/cardano-cli` が展開されます。

`/usr/local/bin` に配置します。
```bash
sudo cp bin/cardano-node /usr/local/bin/cardano-node
sudo cp bin/cardano-cli /usr/local/bin/cardano-cli
sudo chmod +x /usr/local/bin/cardano-node /usr/local/bin/cardano-cli
```

バージョンを確認します。

```bash
cardano-node --version
cardano-cli --version
```
```yaml title="期待される表示例：" noCopy
cardano-node 11.1.0.164 - linux-x86_64 - ghc-9.6
git rev 6971bb527288d0f362147fbe318c0e9c84312ab3

cardano-cli 11.1.0.0 - linux-x86_64 - ghc-9.6
git rev 6971bb527288d0f362147fbe318c0e9c84312ab3
```
> 末尾に `164` が含まれていれば Leios プロトタイプ用ビルドです。

不要になった作業用ディレクトリを削除します。
```bash
cd $HOME
rm -rf $HOME/leios-bin
```


## 3. 作業ディレクトリと環境変数の設定 [#sec-3]

```bash
echo 'export NODE_HOME=$HOME/cnode' >> $HOME/.bashrc
echo 'export CARDANO_NODE_NETWORK_ID=164' >> $HOME/.bashrc
echo 'export CARDANO_NODE_SOCKET_PATH=$HOME/cnode/db/socket' >> $HOME/.bashrc
source $HOME/.bashrc
mkdir -p "$NODE_HOME"
```


## 4. 設定ファイルの取得 [#sec-4]

設定ファイル（`config.json` / `topology.json` / 各ジェネシスファイル）を取得します。

```bash
cd "$NODE_HOME"
git clone --depth 1 https://github.com/input-output-hk/ouroboros-leios
cp ouroboros-leios/testnet/config/* "$NODE_HOME"/
```


## 5. DBスナップショットの復元 [#sec-5]

ジェネシスからのフル同期には長い時間がかかります。  
公開されている **DBスナップショット** を `$NODE_HOME/db` に復元することで、同期時間を大幅に短縮できます。

<Callout type="warn" title="復元はノード起動前に実施してください">

DBスナップショットの復元は、**ノードを一度も起動していない状態**（`$NODE_HOME/db` が空の状態）で行ってください。  
既にノードを起動して DB が作成されている場合は、先に停止し `db` を空にしてから復元します。

</Callout>


`zstd`を導入します。
```bash
sudo apt install zstd -y
```

スナップショットをダウンロードします。
```bash
cd "$NODE_HOME"
curl -L -o leios.chain.tar.zst https://leios1-rel-a-1.play.dev.cardano.org/leios.chain.tar.zst
```
```bash
curl -L -o leios.leiosdb.tar.zst https://leios3-rel-c-1.play.dev.cardano.org/leios.leiosdb.tar.zst
```

$NODE_HOMEに展開します。
```bash
tar -I zstd -xvf leios.chain.tar.zst -C "$NODE_HOME"
tar -I zstd -xvf leios.leiosdb.tar.zst -C "$NODE_HOME"
```

```bash
cd "$NODE_HOME"
mv db-leios db
```

展開後、不要になったアーカイブを削除します。
```bash
rm -f "$NODE_HOME"/leios.chain.tar.zst "$NODE_HOME"/leios.leiosdb.tar.zst
```


## 6. 起動スクリプトの作成 [#sec-6]

ノードの起動スクリプトを作成します。  
（BP の場合、ブロック生成キーは [BP用キーの生成](/cardano/leios-testnet/bp-key-setup) で作成後に追記します）

```bash
cat > $NODE_HOME/startNode.sh << EOF
#!/bin/bash
DIRECTORY=${NODE_HOME}
PORT=3010
HOSTADDR=0.0.0.0
TOPOLOGY=\${DIRECTORY}/topology.json
DB_PATH=\${DIRECTORY}/db
SOCKET_PATH=\${DIRECTORY}/db/socket
CONFIG=\${DIRECTORY}/config.json
/usr/local/bin/cardano-node run --topology \${TOPOLOGY} --database-path \${DB_PATH} --socket-path \${SOCKET_PATH} --host-addr \${HOSTADDR} --port \${PORT} --config \${CONFIG}
EOF
chmod +x $NODE_HOME/startNode.sh
```


## 7. systemdサービスの作成 [#sec-7]

ユニットファイルを作成します。

```bash
cat > $NODE_HOME/cardano-node.service << EOF
# The Cardano Leios Node Service (part of systemd)
# file: /etc/systemd/system/cardano-node.service

[Unit]
Description     = Cardano Leios Node
Wants           = network-online.target
After           = network-online.target

[Service]
User            = ${USER}
Type            = simple
WorkingDirectory= ${NODE_HOME}
ExecStart       = /bin/bash -c '${NODE_HOME}/startNode.sh'
KillSignal      = SIGINT
RestartKillSignal= SIGINT
TimeoutStopSec  = 300
LimitNOFILE     = 32768
Restart         = always
RestartSec      = 5
StandardOutput  = syslog
StandardError   = syslog
SyslogIdentifier= cardano-node

[Install]
WantedBy        = multi-user.target
EOF
```

<Callout type="info" title="ExecStartについて">

起動スクリプト内で `/usr/local/bin/cardano-node` を**絶対パス**で呼び出しているため、systemd の最小 PATH 環境でも確実に起動できます。

</Callout>


`/etc/systemd/system` にユニットファイルをコピーし、権限を付与します。
```bash
sudo cp $NODE_HOME/cardano-node.service /etc/systemd/system/cardano-node.service
```
```bash
sudo chmod 644 /etc/systemd/system/cardano-node.service
```

サービスを有効化して起動します。
```bash
sudo systemctl daemon-reload
```
```bash
sudo systemctl enable --now cardano-node
```


## 8. 同期確認 [#sec-8]

ログを確認します。
```bash
journalctl -u cardano-node -f
```

同期状況を確認します。
```bash
cardano-cli query tip
```
> 初回起動時はDB検証が入るため表示されるまで少し時間かかります

```yaml title="期待される表示例：" noCopy
{
  "block": 12345,
  "epoch": 42,
  "era": "Dijkstra",
  "slot": 678910,
  "syncProgress": "100.00"
}
```
> `syncProgress` が `100.00` になればフル同期完了です。


便利なエイリアス設定

```bash
echo "alias cnode='journalctl -u cardano-node -f'" >> $HOME/.bashrc
echo "alias cnstart='sudo systemctl start cardano-node'" >> $HOME/.bashrc
echo "alias cnstop='sudo systemctl stop cardano-node'" >> $HOME/.bashrc
echo "alias cnrestart='sudo systemctl restart cardano-node'" >> $HOME/.bashrc
echo alias cnreload='"pkill -HUP cardano-node"' >> $HOME/.bashrc
source $HOME/.bashrc
```


## 9. gLiveViewのインストール [#sec-9]

`cardano-node` はログが流れる画面だけでは状態が分かりにくいため、ノードの状態を視覚的に確認できる `gLiveView` を導入します。

> `gLiveView` は [Guild Operators](https://cardano-community.github.io/guild-operators/#/Scripts/gliveview) によるツールで、systemd サービスと連携してノードのステータスを表示します。

必要な依存パッケージをインストールし、スクリプト用ディレクトリを作成します。
```bash
mkdir -p $NODE_HOME/scripts
cd $NODE_HOME/scripts
sudo apt install bc tcptraceroute -y
```

`gLiveView` 本体と `env` ファイルをダウンロードします。
```bash

curl -s -o gLiveView.sh https://raw.githubusercontent.com/cardano-community/guild-operators/master/scripts/cnode-helper-scripts/gLiveView.sh
curl -s -o env https://raw.githubusercontent.com/cardano-community/guild-operators/master/scripts/cnode-helper-scripts/env
chmod 755 gLiveView.sh
```

`env` ファイルの定義を、本マニュアルの構成（ポート `3010`）に合わせて修正します。
```bash
sed -i $NODE_HOME/scripts/env \
    -e '1,73s!#CNODE_HOME="/opt/cardano/cnode"!CNODE_HOME="'${NODE_HOME}'"!' \
    -e '1,73s!#CNODE_PORT=6000!CNODE_PORT=3010!' \
    -e '1,73s!#UPDATE_CHECK="Y"!UPDATE_CHECK="N"!' \
    -e '1,73s!#CONFIG="${CNODE_HOME}/files/config.json"!CONFIG="${CNODE_HOME}/config.json"!' \
    -e '1,73s!#SOCKET="${CNODE_HOME}/sockets/socket"!SOCKET="${CNODE_HOME}/db/socket"!' \
    -e '1,73s!#PROM_HOST=127.0.0.1!PROM_HOST=127.0.0.1!' \
    -e '1,73s!#PROM_PORT=12798!PROM_PORT=12798!'
```

<Callout type="info" title="修正される定義">

| 項目 | 値 |
| :---- | :---- |
| `CNODE_HOME` | `$NODE_HOME`（`$HOME/cnode`） |
| `CNODE_PORT` | `3010` |
| `CONFIG` | `${CNODE_HOME}/config.json` |
| `SOCKET` | `${CNODE_HOME}/db/socket` |
| `PROM_PORT` | `12798` |

</Callout>

任意の単語で起動できるようエイリアスを登録します。
```bash
echo "alias glive='cd $NODE_HOME/scripts; ./gLiveView.sh'" >> $HOME/.bashrc
source $HOME/.bashrc
```


`gLiveView` を起動します。
```bash
glive
```
