DMQ（Decentralized Message Queue）は、Mithril Signerが署名を分散型の方法で交換するためのプロトコルです。
Mithrilネットワークの堅牢性とスケーラビリティを向上させ、DMQが十分に普及することで複数のAggregatorを同時に稼働できるようになり、Mithrilプロトコル全体の可用性向上につながります。


<Callout type="info" title="情報">

以下の構成により、DMQ NodeをMainnet環境にデプロイできます。  
最新安定版の`DMQ Node 0.7.0.0`と`Mithril Signer 1.1.6`の組み合わせです。

</Callout>

<Callout type="tip" title="補足">

以下の手順は、[Mithril Signerノードの設定](/cardano/operation/mithril-signer-node-setup-and-updates)を行っている方のみ対象です。


<Tabs items={["BP"]}>
<Tab value="BP">

Mithril Signerのバージョンを確認します。
```bash
mithril-signer -V
```

`1.1.6`であることを確認し、以降の手順へ進んでください。
```yaml title="期待される表示例：" noCopy
mithril-signer 1.1.6+23e124d
```

</Tab>
</Tabs>

</Callout>

## DMQ Nodeのインストール [#sec-1]

システムのアップデート
```bash
sudo apt update && sudo apt upgrade -y
```

作業ディレクトリの作成
```bash
mkdir -p $HOME/git/mithril/dmq
cd $HOME/git/mithril/dmq
```

ビルド済みバイナリファイルのダウンロード
```bash
wget -O dmq-node.tar.gz https://github.com/IntersectMBO/dmq-node/releases/download/0.7.0.0/dmq-node-linux.tar.gz
```

解凍してtar.gzファイルの削除
```bash
tar -xzf dmq-node.tar.gz --strip-components=2 result/bin
rm dmq-node.tar.gz
```

バイナリファイルをシステムフォルダへコピー
```bash
sudo cp dmq-node /usr/local/bin/dmq-node
```

システムに反映されたバージョン確認
```bash
dmq-node --version
```

```yaml title="期待される表示例：" noCopy
dmq-node version: 0.7.0.0
```


## ソケット・設定ディレクトリ作成 [#sec-2]

### DMQ Node設定ディレクトリの作成

設定ファイル格納ディレクトリの作成
```bash
mkdir -p $HOME/mithril/dmq
```

DMQ Nodeソケットパス
```bash
grep -q '^export DMQ_NODE_SOCKET_PATH=' $HOME/.bashrc || echo "export DMQ_NODE_SOCKET_PATH=\"$HOME/mithril/dmq/socket\"" >> $HOME/.bashrc
source $HOME/.bashrc
```

設定内容の確認
```bash
echo $DMQ_NODE_SOCKET_PATH
```

```yaml title="期待される表示例：" noCopy
/home/<USER>/mithril/dmq/socket
```

## トポロジーファイル作成 [#sec-3]

<Tabs items={["リレー", "BP"]}>
<Tab value="リレー">

<Callout type="warn" title="クラウドのセキュリティグループでファイアウォールを開けている場合">

`ufw`は使わず、コンソールでBPサーバーからDMQ通信に使用するIPのみ、RelayサーバーのDMQポート（例: 6161）へのインバウンド通信を許可してください。

</Callout>


```bash
sudo ufw allow from <BPのIP> to any port 6161 proto tcp
```

```bash
sudo ufw reload
```

DMQ Bootstrap PeerのIPとポート番号をすでに入力しているので、そのまま実行してください。
```bash
cat > $HOME/mithril/dmq/${NODE_CONFIG}-dmq-topology.json << EOF
{
  "bootstrapPeers": [],
  "localRoots": [
    {
      "accessPoints": [
        {
          "address": "35.233.75.24",
          "port": 6161
        }
      ],
      "advertise": true,
      "trustable": false,
      "hotValency": 1
    }
  ],
  "peerSnapshotFile": null,
  "publicRoots": []
}
EOF
```

</Tab>
<Tab value="BP">

## systemd サービス作成 [#sec-4]

<Tabs items={["リレー", "BP"]}>
<Tab value="リレー">

```bash
cat > $HOME/mithril/dmq/dmq-node.service << EOF
[Unit]
Description=DMQ relay service
Wants=network-online.target
After=network-online.target cardano-node.service
StartLimitIntervalSec=0

[Service]
User=${USER}
Type=simple
WorkingDirectory=$NODE_HOME
Restart=always
RestartSec=60
LimitNOFILE=32768
StandardOutput=syslog
StandardError=syslog
SyslogIdentifier=dmq-node
ExecStart=/usr/local/bin/dmq-node --configuration-file $HOME/mithril/dmq/${NODE_CONFIG}-dmq-config.json --topology-file $HOME/mithril/dmq/${NODE_CONFIG}-dmq-topology.json --local-socket ${DMQ_NODE_SOCKET_PATH} --host-addr $(curl -s https://api.ipify.org) --port 6161

[Install]
WantedBy=multi-user.target
EOF
```

</Tab>
<Tab value="BP">

```bash
cat > $HOME/mithril/dmq/dmq-node.service << EOF
[Unit]
Description=DMQ block producer service
Wants=network-online.target
After=network-online.target cardano-node.service
StartLimitIntervalSec=0

[Service]
User=${USER}
Type=simple
WorkingDirectory=$NODE_HOME
Restart=always
RestartSec=60
LimitNOFILE=32768
StandardOutput=syslog
StandardError=syslog
SyslogIdentifier=dmq-node
ExecStart=/usr/local/bin/dmq-node --configuration-file $HOME/mithril/dmq/${NODE_CONFIG}-dmq-config.json --topology-file $HOME/mithril/dmq/${NODE_CONFIG}-dmq-topology.json --local-socket ${DMQ_NODE_SOCKET_PATH} --host-addr $(curl -s https://api.ipify.org) --port 6161

[Install]
WantedBy=multi-user.target
EOF
```

</Tab>
</Tabs>

システムディレクトリへ配置
```bash
sudo cp $HOME/mithril/dmq/dmq-node.service /etc/systemd/system/dmq-node.service
```
```bash
sudo chmod 644 /etc/systemd/system/dmq-node.service
```

サービス設定反映
```bash
sudo systemctl daemon-reload
```

自動起動登録して起動
```bash
sudo systemctl enable dmq-node --now
```

状態確認
```bash
sudo systemctl status dmq-node --no-pager
```
```yaml title="期待される表示例：" noCopy
● dmq-node.service - DMQ xxx service
~
     Active: active (running)
```

ログの確認
```bash
journalctl -u dmq-node -f
```

DMQ Peerとの接続状態を確認します。

```bash
sudo journalctl -u dmq-node -n 200 -o cat | grep 'HandshakeSuccess'
```
> `HandshakeSuccess`に関するログが出力されていることを確認します。

エイリアス設定
```bash
echo alias dmqnode='"journalctl -u dmq-node -f"' >> $HOME/.bashrc
source $HOME/.bashrc
```
